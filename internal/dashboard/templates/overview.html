Getting started

Three steps and the first page is live. Each is marked done once it has happened on this instance.

  1. {{if .Data.LocalAccounts}}Invite a person{{else}}Add a person{{end}}{{if .Data.Invited.Done}} Done{{end}} {{if .Data.LocalAccounts}}You get a link to copy and send. It works once, and Kazari sends no email. {{if not .Data.Invited.Done}}Invite a person{{else}}Invite another{{end}} {{else}}People sign in at your identity provider. Whoever it admits appears under People at their first sign-in. See people{{end}}
  2. Connect an agent{{if .Data.Connected.Done}} Done{{end}} Add this address as a connector in your AI agent, then sign in when it asks. In claude.ai and the Claude desktop app: Settings, then Connectors, then Add custom connector. {{template "overview-connector" .}}
    From a terminal

    Claude Code adds the connector with one command:

    claude mcp add --transport http kazari {{.Data.MCPURL}}

    The kazari command line publishes a directory with an API key, which you issue on a person's page:

    export KAZARI_URL={{.Data.CLIURL}}
export KAZARI_TOKEN=kzk_...
kazari publish ./site --slug hello
  3. Publish a first page{{if .Data.Shipped.Done}} Done{{end}} Ask the agent for a page and tell it to publish with Kazari. It answers with the page's address. See pages
