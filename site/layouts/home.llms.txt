# {{ site.Title }}

> {{ .Description }}

Kazari is open source (MIT) and runs as one Go binary with SQLite and a directory of files. Each artifact is served at its own subdomain under one wildcard certificate (`<slug>.art.example.com`), and every version keeps an address of its own (`<slug>--v3.art.example.com`). Agents publish through the MCP server at `mcp.`, scripts through the REST API at `api.` or the `kazari` CLI, and operators use the admin API at `admin.`. People sign in through the organisation's OpenID Connect provider; MCP clients use OAuth 2.1 or an API key.
